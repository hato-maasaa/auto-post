# プロダクト仕様書: One Source Two Post Dashboard

## 1. ツールのコンセプト
**「ワンソース・ツーポスト (One Source, Two Posts)」**
ベースのアイデアを1回入力するだけで、note用の“売れる記事”とX用の“バズ狙いポスト”をAIが自動生成し、投稿まで完結させるダッシュボードです。

*   **Core Value**: 普段の「note書く→Xにも告知文考える→別タブ往復してコピペ・投稿」という面倒な作業時間を大幅に削減します。
*   **仕組み**:
    1.  アイデアを1回入力する。
    2.  AIがnote記事とXポストを自動生成する。
    3.  1画面で確認・修正し、ボタン一つで各プラットフォームへ投稿する。

## 2. ユーザーフロー (利用イメージ)
1.  **ダッシュボードを開く**: ローカルのNext.jsアプリを起動します。
2.  **フォームに入力**: 以下の要素をざっくり入力します。
    *   テーマ / タイトル案
    *   想定読者
    *   伝えたいポイント
    *   売りたいもの（あれば）
3.  **コンテンツ生成**: 「コンテンツ生成」ボタンを押下します。
    *   note用の長文記事 (Markdown)
    *   X用ポスト文 or スレッド案
    *   これらが画面下部に生成されます。
4.  **微修正**:
    *   その場でエディタを使って修正します。
    *   X文字数カウンターなどで長さをチェックします。
5.  **noteに投稿**: 「noteに投稿」ボタンを押下します。
    *   Playwrightが裏で自動的にnote編集画面を開き、タイトル・本文を入力して「下書き保存」または「公開」まで実行します。
6.  **Xに投稿**: 「Xに投稿」ボタンを押下します。
    *   API経由で即時投稿されます。
7.  **ログ確認**: 投稿ログで履歴（日時、タイトル、URL）を確認します。

## 3. 機能構成 (MVP)

### A. ネタ入力フォーム
*   タイトル/テーマ
*   ターゲット読者
*   要点・箇条書き
*   トーン選択（ラフ / 丁寧 / エモい など）

### B. AIコンテンツ生成
*   **noteエリア**: 長文記事生成 (Markdown/HTML)
*   **Xエリア**: 短文ポスト生成 (単発 or スレッド)
*   それぞれのエリアに独立して表示し、比較・編集しやすくする。

### C. エディタ機能
*   **note側**: Markdownプレビュー付きのリッチテキスト（簡易版）
*   **X側**: 文字数カウンター、140字超え警告、スレッド分割表示

### D. 投稿機能
*   **X連携**: API (POST /2/tweets) を使用して直接投稿。
*   **note連携**: Playwrightを使用したブラウザ自動操作。
    *   ログイン済みセッションの利用
    *   新規投稿画面への遷移と入力
    *   「公開」または「下書き保存」の実行

### E. 投稿ログ
*   投稿日時の記録
*   noteタイトル、XのURLなどの一覧表示

## 4. 将来的な拡張性 (Nice-to-Have)
*   **複数テンプレート**:
    *   note: 「ストーリー型」「HowTo型」「失敗談」など
    *   X: 「フック強め」「学び系」「自虐ネタ」など
*   **A/Bパターン生成**: Xの文言を2案生成し、ワンクリックで選択できる機能。
*   **プロンプト管理画面**: UI上から使用するプロンプトを調整可能にする機能。
